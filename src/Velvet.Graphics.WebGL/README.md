# Velvet.Graphics.WebGL

WebGL rendering backend for Velvet3D.

This package provides a WebGL-based graphics implementation using JSInterop for browser environments.

## Features

- WebGL rendering device
- Shader system
- Mesh uploading
- Particle renderer
- JSInterop bridge for browser integration

Part of the Velvet3D ecosystem.
