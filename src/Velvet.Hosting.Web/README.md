# Velvet.Hosting.Web

Blazor hosting layer for Velvet3D.

This package connects Velvet.Core and Velvet.Graphics.WebGL to the browser using JSInterop, enabling rendering inside Blazor applications (WebAssembly and Server). Razor support is included but not the primary target.

## Features

- Blazor WebAssembly integration
- JSInterop bridge to WebGL
- Rendering loop management
- Scene and camera orchestration
- Input and controller support

Part of the Velvet3D ecosystem.
